# Ranged Range Indicator

Colored box under your character showing the distance to your target, for ranged classes.

Works on any living target (monster, or friendly/hostile player) except yourself. Shows an exact `NN yd` when the client provides it, otherwise a bracket like `20 - 30` (or `40+`), or `OUT OF RANGE` if nothing could be determined. The box color is picked from the upper end of the range:
- **Red** `> 30 yd` – out of range
- **Green** `20 - 30 yd`
- **Yellow** `10 - 20 yd`
- **Orange** `5 - 10 yd`
- **Red** `< 5 yd`

## Import
Paste the contents of `import.txt` into WeakAuras (`/wa` → New → Import).
Regenerate with: `python3 tools/build_import.py auras/ranged-range-indicator/aura.py`

## Files
- `aura.py` – aura definition (texture region, position, size, load conditions)
- `trigger.lua` – custom trigger; creates the label, sets the text and box color, runs a ~20x/sec update driver
- `import.txt` – generated import string

## Configuration
- **Color bands**: thresholds/colors in the `if hi > 30 ...` block of the trigger.
- **Position/size**: Display tab (default 120 px below screen center).
- **Classes**: Load tab; the class list (Hunter, Mage, Warlock, Priest, Evoker, Shaman, Druid) is defined but `use_class` is `False` in `aura.py`, so the aura currently loads on all classes. Set it to `True` to restrict it.

## Requirements / known limitations
- Distance sources, in order: `UnitDistanceSquared` (exact), `LibRangeCheck-3.0` (ships with WeakAuras), then a built-in item-range probe. Library/probe results are brackets, not exact yards.
- The import string was generated by script and has not been tested in game. If the import fails, create a new Texture aura (size 140x50, 120 px below center), set Trigger to Custom → Status → Event(s) `PLAYER_TARGET_CHANGED, FRAME_UPDATE`, and paste `trigger.lua` as the code. The trigger draws its own label on the region, so no Display Text is needed.
- Retail "Midnight" restricts some range/unit info in combat; if values go blank in combat, that is the restriction, not the aura.
